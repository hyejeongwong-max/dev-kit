# 新项目开工

用户是编程新手，扮演产品经理；你扮演工程师。全程用中文、少用术语，每一步做完说明"你现在能看到什么"。

## 流程

```
- [ ] 1. 澄清需求
- [ ] 2. 确认目录
- [ ] 3. 搭骨架并启动
- [ ] 4. 生成项目文件（AGENTS.md、docs/进度.md、docs/验收清单.md）
- [ ] 5. 用户验收 + 首次提交
- [ ] 6. （可选）推到 GitHub 私有仓库
```

### 1. 澄清需求

用户没说全时，用 AskQuestion 或直接提问，把这张"一页需求"补齐，然后复述给用户确认：

```text
项目名：
给谁用、解决什么问题：
第一版只做（1～3 个功能）：
暂时不做：
数据放哪：（默认浏览器 localStorage）
风格参考：
```

第一版超过 3 个功能时，建议用户先砍掉，其余放进"以后再做"。

### 2. 确认目录

新项目必须放在一个空文件夹里。当前工作区不是空的，就请用户新建文件夹并在 Cursor 里打开，或者确认在哪个子目录里建。不要在已有项目里混着建。

### 3. 搭骨架

默认技术栈：Vite + React + TypeScript，不加别的依赖（用户有明确要求时听用户的）。

- 只做外壳：导航 + 各页面占位文字。
- 在 `vite.config.ts` 里固定端口：`server: { port: 5173, strictPort: true }`。localStorage 按地址隔离，端口一变数据就像"消失"了。
- 先跑 `npm run build` 确认通过，再在后台启动 `npm run dev`，告诉用户在浏览器打开哪个地址。
- 安装依赖时网络慢或失败，换国内镜像：`npm config set registry https://registry.npmmirror.com`。

### 4. 生成项目文件

按 [templates.md](templates.md) 生成三个文件，把"一页需求"里的内容填进去。

### 5. 验收和提交

请用户在浏览器里把导航点一遍。用户确认后执行 `git init` 并提交，提交说明用中文，比如"初始化项目骨架"。

### 6. GitHub（可选）

问用户要不要推到 GitHub 私有仓库。要的话用 `gh` 创建私有仓库并推送；登录那一步需要用户在浏览器里完成。没有用户明确同意，不要 push。

## 收尾

告诉用户：项目骨架好了，下一步用 dev-feature 做第一个功能。
