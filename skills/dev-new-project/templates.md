# 新项目文件模板

花括号 `{}` 里的内容替换成"一页需求"中的实际信息。

## AGENTS.md

```markdown
# {项目名}

{一句话：给谁用、解决什么问题}。用户是编程新手。

## 技术
- Vite + React + TypeScript
- 数据存在 localStorage，key 统一用 "{前缀}." 开头
- 开发端口固定 5173
- 不要随便新增依赖包，需要时先问我

## 规矩
- 只改我要求的部分，不要顺手重构别的地方
- 改完运行 `npm run build`，确认没有报错，并告诉我怎么验证
- 改数据结构时必须兼容已有数据
- 用中文回复，解释时少用术语
- 拿不准的地方先问我，不要自己猜
- 单个文件超过 300 行时提醒我拆分
- 每完成一个功能，更新 docs/进度.md 和 docs/验收清单.md
- 没有我同意，不要删除文件，不要 git push

## 设计规范
- {风格参考，例如：背景浅灰 #f5f5f7，卡片白色，圆角 16px，间距用 8 的倍数}
- 新页面沿用已有的按钮、卡片组件，不要另写一套样式

## 开发工具箱
- 直接说想做什么（加功能、修 bug、测试、上线、记进手册），dev-kit 会判断场景、确认后带着走
- 开发手册：{dev-handbook 技能"配置"里的手册链接；没有配置就删掉这一行}
```
